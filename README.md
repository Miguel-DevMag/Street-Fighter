# Street Fighter - Promotional Landing Page 🥋

Uma landing page imersiva e interativa desenvolvida para promover o universo de Street Fighter (com a temática de um filme/evento para 2026). O projeto apresenta uma interface inspirada em HUDs futuristas e táticos, com foco em design dinâmico, animações fluidas e uma experiência de usuário envolvente.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as principais tecnologias do desenvolvimento web frontend:

- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização avançada, com uso intensivo de variáveis, flexbox/grid, animações (keyframes), efeitos de *glassmorphism* (vidro) e tipografia personalizada (Inter e Orbitron).
- **JavaScript (Vanilla):** Lógica de interatividade, controle do carrossel de personagens, efeitos de cursor customizado e animações de interface.

---

## ✨ Funcionalidades

- **Hero Video Background:** Vídeo em loop na tela inicial para imersão imediata.
- **Menu de Navegação:** Menu *sticky* com efeito de vidro (glassmorphism) e design tático.
- **Seção de Trailer Oficial:** Player de vídeo integrado com design de câmera de combate (HUD).
- **Carrossel de Lutadores:** Seleção interativa de personagens (Ryu, Ken, Chun-Li, Guile, Cammy, M. Bison) exibindo seus atributos dinâmicos em barras de progresso.
- **Insights de Combate (Mídia):** Layout em três colunas para exibição de imagens premium com efeitos interativos.
- **Arena da Comunidade (Depoimentos):** Efeito *marquee* (letreiro digital) exibindo comentários dos fãs em loops contínuos.
- **Cursor Personalizado:** Cursor tático que acompanha o movimento do mouse, aumentando a sensação de controle do sistema.

## 🛠️ Como Executar o Projeto

1. Faça o clone deste repositório para sua máquina local:
   ```bash
   git clone https://github.com/SEU_USUARIO/Street-Fighter.git
   ```

2. Navegue até a pasta do projeto:
   ```bash
   cd Street-Fighter
   ```

3. Abra o arquivo `index.html` diretamente em seu navegador preferido ou utilize uma extensão como o **Live Server** (no VS Code) para emular um servidor local.
